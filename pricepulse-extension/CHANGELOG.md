# Changelog

All notable changes to PricePulse will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-11-03

### Added
- Initial release of PricePulse
- Price tracking for major e-commerce sites (Amazon, eBay, Walmart, Best Buy, Target, Etsy, AliExpress)
- Real-time price monitoring with customizable check intervals
- Price drop notifications
- Target price alerts
- Beautiful popup UI with tracking, wishlist, and deals tabs
- Comprehensive dashboard with analytics
- Price history visualization
- Settings page with full customization options
- Onboarding flow for new users
- Support for multiple currencies (USD, EUR, GBP, CAD, AUD)
- Local data storage with privacy protection
- Responsive design for all screen sizes
- Accessibility features (ARIA labels, keyboard navigation)
- Smooth animations and micro-interactions

### Features
- **Smart Product Detection**: Automatically detects products on supported sites
- **Floating Track Button**: One-click price tracking from product pages
- **Badge Counter**: Shows number of tracked items on extension icon
- **Search & Filter**: Quickly find tracked products
- **Sort Options**: Sort by price, date, discount, and more
- **Wishlist Management**: Organize products with heart icon
- **Deal Finder**: Automatically highlights best price drops
- **Stats Dashboard**: Track savings and price drop trends

### Supported Sites
- Amazon (US, UK, CA, DE, FR)
- eBay
- Walmart
- Best Buy
- Target
- Etsy
- AliExpress
- Shopify stores
